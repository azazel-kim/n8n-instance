# 한글 문서 자동 생성 시스템

n8n 워크플로우와 HWP 서비스를 연동하여 한글(HWP/HWPX) 문서를 자동으로 생성하는 시스템입니다.

## 제공되는 워크플로우

| 파일명 | 설명 | 용도 |
|--------|------|------|
| `hwp-document-generator.json` | 기본 문서 생성기 | 일반 문서 자동 작성 |
| `irb-document-generator.json` | IRB 문서 생성기 | 연구윤리 심의 문서 자동화 |

## 시스템 아키텍처

```

├─────────────────┬─────────────────┬─────────────────────────────────┤

│  (Form Trigger) │  (내용 생성)     │     (JSON 구성)                 │
└────────┬────────┴────────┬────────┴─────────────┬───────────────────┘
         │                 │                      │
         ▼                 ▼                      ▼
┌─────────────────────────────────────────────────────────────────────┐
│                      HWP Service (localhost:8765)                   │
├─────────────────┬─────────────────┬─────────────────────────────────┤
│   pyhwpx        │    HWPX XML     │      템플릿 관리                 │
│  (한글 자동화)   │   (직접 처리)    │   (IRB 서식 등)                 │

         │                 │
```

## 빠른 시작

### 1. HWP 서비스 실행 (Windows + 한글 설치 환경)

```bash
cd workflows/hwp-service
pip install -r requirements.txt
python hwp_service.py
```

### 2. n8n 워크플로우 Import

1. n8n에서 **Workflows > Import from File**
2. `irb-document-generator.json` 또는 `hwp-document-generator.json` 선택

### 3. Credentials 설정

- **Anthropic API**: Claude AI 사용
- **Google Drive OAuth2**: 클라우드 저장
- **Gmail OAuth2**: 이메일 알림

### 4. 워크플로우 활성화 및 사용

1. 워크플로우 **Active** 토글
2. Form URL 접속
3. 정보 입력 후 제출

## HWP 처리 방식

### 방식 1: pyhwpx (Windows 전용, 권장)

한글 프로그램이 설치된 Windows 환경에서 완벽한 HWP 지원.

**장점:**
- 기존 HWP 템플릿 100% 호환
- 누름틀 필드 자동 채우기
- 모든 서식 유지

**요구사항:**
- Windows OS
- 한컴오피스 한글 설치
- Python 3.8+

### 방식 2: HWPX XML 직접 처리 (크로스 플랫폼)

한글 프로그램 없이 HWPX 파일의 XML 구조를 직접 수정.

**장점:**
- 한글 프로그램 불필요
- Linux/Mac 지원
- 서버 환경 적합

**제한:**
- HWPX 형식만 지원 (HWP 미지원)
- 복잡한 서식은 깨질 수 있음

### 방식 3: HTML Fallback

HWP 서비스 사용 불가 시 HTML로 대체 생성.

**장점:**
- 어디서든 작동
- 한글에서 HTML 불러오기 가능

## IRB 문서 자동화

### 지원하는 서식

| 서식 번호 | 문서명 | 자동화 수준 |
|----------|--------|------------|
| 서식 02 | 연구계획서 | ✅ 완전 지원 |
| 서식 03-1 | 연구참여 설명서 | ✅ 완전 지원 |
| 서식 03-2 | 연구참여 동의서 | ✅ 완전 지원 |
| 서식 14 | 연구윤리 준수 서약서 | ✅ 완전 지원 |
| 서식 20 | 개인정보 처리 동의서 | ✅ 완전 지원 |
| 서식 31 | 이해상충 공개서약서 | ✅ 완전 지원 |

### 워크플로우 사용 흐름

```
1. 웹 폼에서 연구 정보 입력
   - 연구과제명, 연구자 정보
   - 연구 목적, 방법
   - 대상자 선정 기준 등

2. Claude AI가 IRB 문서 내용 생성
   - 전문적인 표현으로 재작성
   - 윤리 심의 기준에 맞게 구성

3. HWP 서비스가 템플릿에 내용 채움
   - 기존 IRB 서식 템플릿 사용
   - 필드별 자동 매핑

4. 완성된 문서 저장 및 알림
   - Google Drive 업로드
   - 이메일로 다운로드 링크 발송
```

## 템플릿 준비 방법

### 누름틀 필드 추가 (한글 프로그램)

1. 템플릿 문서 열기
2. 필드 위치에 커서
3. **입력 > 누름틀 > 일반**
4. 필드 이름 입력 (예: `{{연구과제명}}`)
5. 저장

### 사용 가능한 필드명

```
- {{연구과제명}}
- {{연구책임자}}
- {{소속}}
- {{연구목적}}
- {{연구방법}}
- {{연구대상자수}}
- {{소요시간}}
- {{선정기준}}
- {{제외기준}}
- {{잠재적위험}}
- {{잠재적이익}}
- {{비밀보장}}
- {{보상내용}}
- {{작성일}}
```

## API 엔드포인트 (HWP Service)

| Method | Endpoint | 설명 |
|--------|----------|------|
| GET | `/` | 서비스 상태 확인 |
| GET | `/templates` | 템플릿 목록 조회 |
| POST | `/irb/generate` | IRB 문서 세트 생성 |
| POST | `/process` | 일반 템플릿 처리 |
| GET | `/download/{filename}` | 파일 다운로드 |

## 문제 해결

| 증상 | 원인 | 해결 방법 |
|------|------|----------|
| HWP 서비스 연결 실패 | 서비스 미실행 | `python hwp_service.py` 실행 |
| 한글 연결 오류 | 한글 미설치 | 한컴오피스 설치 |
| 템플릿 필드 미적용 | 누름틀 미설정 | 템플릿에 누름틀 필드 추가 |
| HWPX 처리 오류 | 구버전 파일 | 한글에서 HWPX로 재저장 |
| API 오류 | Credential 문제 | n8n Credentials 재설정 |
